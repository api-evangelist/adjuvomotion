# Adjuvo Motion B.V. (SenseGlove)

> Adjuvo Motion B.V. trades publicly as SenseGlove, a Dutch haptics company in Rotterdam and Delft.
> It builds force-feedback and vibrotactile gloves for virtual and extended reality — Nova 2, Nova,
> DK1 — and the R1 exoskeleton glove for tele-robotics and imitation learning. Its developer surface
> is a NATIVE DEVICE API, not a web service: there is no public HTTP, REST, GraphQL, gRPC or SOAP
> API, no API keys, no OAuth, no rate limits and no hosted endpoint. Integration happens in-process
> against a C++/C# library, or through the first-party Unity and Unreal Engine plugins and ROS
> packages.

Generated by API Evangelist from the company's own public surface on 2026-09-07. Provider does not
publish an llms.txt of its own (probed: https://www.senseglove.com/llms.txt → 404,
https://unity.docs.senseglove.com/llms.txt → 404, https://unreal.docs.senseglove.com/llms.txt → 404).

## The API

- [Core API introduction](https://senseglove.gitlab.io/SenseGloveDocs/native/core-api-intro.html): C++ and C# libraries; headers in `incl/`, per-platform `.lib`/`.dll` in `lib/`. Everything written by SenseGlove lives in the `SGCore` namespace.
- [Core API architecture](https://senseglove.gitlab.io/SenseGloveDocs/native/core-api-arch.html): `DeviceList` is the entry point to connected hardware; `SGDevice` is the abstract device base; concrete classes per glove model.
- [SGCore calibration functions](https://senseglove.gitlab.io/SenseGloveDocs/native/core-calibration.html)
- [SGCore Nova 2.0 functions](https://senseglove.gitlab.io/SenseGloveDocs/native/core-nova2.html)
- [SGCore HandPose reference](https://senseglove.gitlab.io/SenseGloveDocs/native/handpose-core.html)
- [Examples](https://senseglove.gitlab.io/SenseGloveDocs/native/examples.html)

Connection model: applications do not talk to the glove directly. SGConnect (a C++ library) or the
SenseCom desktop process owns the device connection in the background; the Core API attaches to it.
Three haptic modalities are exposed — force feedback, vibrotactile, and wrist squeeze.

## What this provider does NOT publish

No OpenAPI or Swagger. No GraphQL. No AsyncAPI, webhooks or event stream. No gRPC/Protobuf or WSDL.
No MCP server and no A2A agent card. No /.well-known/ document on any live host. No status page, no
published SLA, no deprecation policy, no rate limits, no API plans, and no package on npm, PyPI,
NuGet, Maven Central, crates.io, OpenUPM or the ROS index — every artifact ships from GitHub or an
engine marketplace. The legacy corporate domain adjuvomotion.com returns HTTP 500 on every path.
